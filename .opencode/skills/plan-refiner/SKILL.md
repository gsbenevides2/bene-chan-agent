# O que é um plano de implementação?
Um plano de implementação é um documento em markdown que fica na pasta plans do projeto, nele é descrito todos os detalhes de como vai ser feita a implementação de algo no projeto.

## Pontos importantes:
Ao refinar um plano sempre se atente as seguintes questões:
1. Analise os arquivos do projeto e questione possíveis duvídas que encontrar olhando os arquivos e o plano.
